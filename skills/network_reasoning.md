# 网络歧义辅助 Skill

本 Skill 只用于根据调用方提供的已有 IR、Evidence 和明确任务文字，提出少量网络语义歧义的候选解释。
它不查看未提供的图片，不替代程序的确定性计算、去重和验证，也不返回平台 Payload。

## 输入边界

- 仅使用当前任务中明确给出的节点、接口、地址、前缀、链路、区域和 Evidence。
- 区分视觉事实、调用方已有事实、候选解释和模型推断。
- 不把模型训练知识或常见网络设计当作当前拓扑事实。
- 输入证据互相冲突时列出冲突，不选一个看起来更常见的答案。
- 缮信息时输出不确定性和理由，不生成缺失数据。

## 广播域语义线索

- 二层交换机及其直接连接成员通常提供广播域候选线索。
- 三层设备的不同接口通常属于不同广播域，但最终归属由程序根据链路和接口验证。
- 交换机互连、点到点链路和区域分组不能仅凭名称视为同一广播域。
- 区域边界是视觉分组，不等于广播域边界。
- 相同网段文字可作为候选线索，但不能覆盖明确物理连接证据。
- 最终广播域成员、唯一性和一致性由程序计算。

## CIDR 与前缀线索

- 图片或 IR 明确给出的 IP/前缀是首要依据。
- 同一候选广播域中多个明确且一致的前缀可支持缺失前缀的候选解释。
- 裸 IP 本身不能证明 `/24` 或其他前缀。
- 前缀冲突必须显式报告，不能选择多数值后隐藏少数证据。
- 地址落在不同网络时提示广播域、识别或绑定可能有误。
- 最终 CIDR 使用标准库或等价确定性程序计算和验证。

## 网关语义线索

- 路由器、防火墙或接口可成为网关候选。
- “gateway” 等明确文字可作为证据，但必须与已有接口和地址对应。
- 网关候选应位于候选 CIDR 内，且不与终端地址冲突。
- 多个三层接口同样合理时保留全部候选，并说明无法消解的证据缺口。
- 不自行选择最小地址、`.1` 或其他常见地址作为网关。
- 最终网关选择及合法性由程序完成。

## 接口与地址一致性风险

- 同一广播域的重复 IP 是阻塞风险。
- 同一接口被绑定到互斥广播域是阻塞风险。
- 同一接口被多条不合理物理链路复用是风险。
- IP 与接口文字距离、链路端点和节点归属不一致时保留多个解释。
- IP 不属于候选 CIDR 时指出具体矛盾，不修改 IP 数字。
- 前缀缺失、地址字符模糊或接口名不完整时保留 unresolved。
- 不根据一致性要求改写清晰的视觉原文。

## 事实、候选与推断

- 直接引用已有 IR 或 Evidence 时标明其来源。
- 候选解释说明支持证据和反对证据。
- 模型推断不能写成视觉事实。
- 置信度反映证据充分程度，不表示程序验证已通过。
- 无唯一答案时明确阻塞原因和建议补充的证据。
- 不删除既有不确定性来制造单一结论。

## 程序职责

以下结论必须由程序最终执行：

- 节点、接口和链路去重。
- 稳定临时 ID 和所有引用生成。
- 广播域成员计算。
- IPv4、前缀和 CIDR 计算。
- 网关选择和网段包含检查。
- 重复 IP、接口复用和图一致性验证。
- 阻塞项是否允许进入编译阶段。

模型只返回候选解释、风险、不确定性和理由。

## 禁止事项

- 不生成最终内部 ID 或平台 ID。
- 不生成图片或 IR 中不存在的 IP、接口、节点或链路。
- 不假设裸 IP 的前缀。
- 不生成 OSPF、静态路由、NAT、端口映射或安全策略。
- 不绕过程序验证或声称已完成最终一致性验证。
- 不返回平台节点、Network、Subnet、NIC、Link 或完整 Payload。
- 不生成 `projectId`、`networkId`、`imageId`、Flavor 或平台 UUID。
- 不使用固定样例、文件名、哈希或预期数量决定结果。

输出必须遵循当前 Schema；若 Schema 允许，使用候选、风险、理由和 unresolved 表达不确定性。
